Интеграция ЖКХНСО.рф для Home Assistant для получения информации о счётчиках и тарифах в Российской Федерации, Новосибирской области.

## Установка

### HACS

[![Откройте свой экземпляр Home Assistant и перейдите к репозиторию в магазине Home Assistant Community Store.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=zebooka&repository=hass-zkhnso&category=integration)

1. Откройте **HACS** в Home Assistant и выполните поиск **ЖКХНСО** (или воспользуйтесь кнопкой выше).
2. Откройте **ЖКХНСО**, выберите **Скачать** (Download) и подтвердите действие.
3. Перезапустите Home Assistant, а затем перейдите к разделу [Настройка](#Настройка).

### HACS: пользовательский репозиторий

1. В HACS откройте **⋮ → Пользовательские репозитории**.
2. Добавьте `https://github.com/zebooka/hass-zkhnso` с типом **Integration**.
3. Найдите **ЖКХНСО** и установите интеграцию.
4. Перезапустите Home Assistant.
5. Добавьте интеграцию через **Настройки → Устройства и службы**.

### Ручная установка

1. Скопируйте папку `zkhnso` в папку `custom_components` в вашем Home Assistant.
2. Перезапустите Home Assistant.
3. Добавьте интеграцию через **Настройки → Устройства и службы**.

## Настройка

Эта интеграция может быть настроена через пользовательский интерфейс Home Assistant:

1. Откройте **Настройки → Устройства и службы**.
2. Нажмите `+ Добавить интеграцию`.
3. Поищите **ЖКХНСО**.
4. Заполните параметры учётной записи.

Используются логин и пароль от личного кабинета ЖКХНСО. Данные проверяются до создания интеграции. Если пароль изменился, Home Assistant предложит повторно пройти аутентификацию.

Настройки предыдущих версий несовместимы с новой версией: удалите прежнюю запись интеграции и настройте её заново. Созданные ранее устройства и сущности могут отличаться от новых.

## Возможности интеграции

- Получать список активных счётчиков (вкл. серийный номер, тип счётчика, дата следующей поверки, текущее значение, дата предыдущей передачи показаний).
- Получать список архивных счётчиков.
- Получать список тарифов и нормативов.
- Получать номер лицевого счёта, адрес, управляющую компанию (название + адрес).
- Создавать событие о приближающейся поверке счётчика.

Данные обновляются один раз в час. Интеграция создаёт отдельное устройство с сенсорами счётчиков и тарифов для каждого лицевого счёта. В параметрах интеграции выберите счёт и тарифы для расчёта суммарных тарифов; при выборе теплоносителя также задайте тариф и норматив подогрева.

### Событие о поверке счётчика

Событие `zkhnso_meter_verification_alert` отправляется, когда до даты поверки включённого активного сенсора счётчика остаётся 30 календарных дней или меньше, в том числе если дата уже прошла. Для одного счётчика и одной даты оно отправляется не более одного раза, в том числе после перезапуска Home Assistant. После изменения даты поверки возможно новое событие. Архивные и отключённые счётчики не проверяются.

Данные события: `entry_id`, `entity_id`, `account_id`, `meter_id`, `serial_number`, `name`, `next_verification_date`, `days_left`. Для прошедшей даты `days_left` отрицателен. Адрес в событие не включается.

События не сохраняются шиной Home Assistant: если при запуске автоматизация ещё не загрузилась, она может пропустить событие. Отметка об отправке сохраняется до отправки, поэтому при сбое между этими действиями событие также может быть пропущено.

Пример автоматизации:

```yaml
automation:
  - alias: Поверка счётчика
    triggers:
      - trigger: event
        event_type: zkhnso_meter_verification_alert
    actions:
      - action: persistent_notification.create
        data:
          title: Приближается поверка счётчика
          message: >-
            {{ trigger.event.data.name }} №{{ trigger.event.data.serial_number }},
            ЛС: №{{ trigger.event.data.account_id }}:
            поверка {{ trigger.event.data.next_verification_date | as_timestamp |
            timestamp_custom('%d.%m.%Y') }}
```

## Подсчет трат по счётчикам

Для подсчёта трат на воду в разделе **Энергия** необходимы суммарные тарифы, так как стоимость воды расчитывается через несколько тарифов. Настроить суммарные тарифы можно в настройках интеграции.

Для расчёта суммарных тарифов необходимо несколько условий. Во-первых, УК через ЖКХНСО должна предоставлять следующие варианты тарифов:
- для водоотведения: `ВОДООТВЕДЕНИЕ` или `ОТВЕД. СТОЧ. ВОД СОИ`
- для холодной воды: `ХОЛОДНОЕ ВОДОСНАБЖЕНИЕ` или `ХВ НА СОД-Е ОБЩ.ИМУЩ.`
- для горячей воды: 
  - вариант №1: `ГОРЯЧЕЕ ВОДОСНАБЖЕНИЕ` или `ГВ НА СОД-Е ОБЩ.ИМУЩ.`
  - вариант №2:
    - подогрев: `ГОРЯЧЕЕ ВОДОСНАБЖЕНИЕ (ПОДОГРЕВ)` или `ГВ НА СОИ (ПОДОГРЕВ)` или "ОТОПЛЕНИЕ"
    - теплоноситель: `ГОРЯЧЕЕ ВОДОСНАБЖЕНИЕ (ТЕПЛОНОСИТ)` или `ГВ НА СОИ (ТЕПЛОНОСИТ)` или `ХОЛОДНОЕ ВОДОСНАБЖЕНИЕ` или `ХВ НА СОД-Е ОБЩ.ИМУЩ.`

Во-вторых, если для расчета суммарного тарифа горячей воды используются тарифы на подогрев, то необходимо задать значение **норматива подогрева воды** через настройки интеграции. Значение можно указать вручную, либо автоматически в зависимости от [типа дома и системы ГВС](#норматив-расхода-тепловой-энергии-на-подогрев-холодной-воды-в-новосибирской-области).

Выберите тарифы для каждого счёта в параметрах интеграции. Прежний автоматический подбор из версии `1.1.x` больше не используется: тарифы необходимо выбрать заново. Пустое значение или отсутствие выбранного тарифа делает соответствующий суммарный тариф неизвестным.

* **Закрытая система ГВС** — Контуры отопления и горячей воды не связаны. Подогрев горячей воды идет через теплообменник. Актуально для новостроек. ## Ограничения и устранение неполадок

- Интеграция работает только с личными кабинетами ЖКХНСО Новосибирской области.
- Если сайт ЖКХНСО недоступен, Home Assistant повторит подключение автоматически.
- Новые счётчики, тарифы и лицевые счета/адреса добавляются автоматически.
- Для удаления откройте страницу интеграции в **Настройки → Устройства и службы** и выберите **Удалить**.
